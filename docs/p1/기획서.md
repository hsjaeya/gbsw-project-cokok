# 기획서

## 1. 프로젝트 개요

| 항목 | 내용 |
|------|------|
| 프로젝트명 | COKOK (cook of king of king) |
| 서비스 유형 | 요리 온라인 강의 플랫폼 |
| 목표 | 유튜브 영상 기반 요리 강의를 커리큘럼 형태로 제공 |
| 타겟 사용자 | 요리를 배우려는 일반인 |

---

## 2. 서비스 배경 및 목적

유튜브에 분산된 요리 영상을 섹션과 강의 단위로 구조화하여 수강생이 체계적으로 학습할 수 있는 플랫폼을 구축한다. 영상은 유튜브 임베드 방식을 사용해 별도 저장 비용 없이 운영한다. 강의 등록은 관리자가 직접 담당한다.

---

## 3. 사용자 역할

| 역할 | 설명 |
|------|------|
| STUDENT | 강의 탐색, 수강 신청, 영상 시청, 진도 확인 |
| ADMIN | 강의 등록 및 관리, 카테고리 관리, 회원 조회 |

---

## 4. 핵심 기능

### 4.1 회원 (STUDENT)

| 기능 | 설명 |
|------|------|
| 회원가입 | 이메일 + 비밀번호 + 닉네임 |
| 로그인 / 로그아웃 | JWT Access Token + Refresh Token |
| 강의 탐색 | 카테고리 필터, 키워드 검색 |
| 강의 상세 조회 | 커리큘럼(섹션/강의 단위) 확인 |
| 강의 시청 | YouTube IFrame 플레이어 + 커리큘럼 사이드바, 첫 진입 시 자동으로 수강 이력 생성 |
| 수강 진도 | 영상 완료 시 자동 완료 처리 및 진도율 표시 |
| 마이페이지 | 수강 중인 강의 목록 및 진도율 확인 |

### 4.2 관리자 (ADMIN)

| 기능 | 설명 |
|------|------|
| 강의 등록 / 수정 / 삭제 | 제목, 설명, 카테고리, 난이도, 썸네일 설정 |
| 커리큘럼 구성 | 섹션 추가 → 강의 단위(YouTube URL) 등록 |
| 카테고리 관리 | 카테고리 추가, 수정, 삭제 |
| 회원 목록 조회 | 전체 회원 확인 |

---

## 5. 카테고리

한식 / 양식 / 일식 / 중식 / 베이킹 & 디저트 / 간편식

---

## 6. 강의 난이도

입문 / 초급 / 중급 / 고급

---

## 7. YouTube 영상 연동 방식

관리자가 강의 단위에 YouTube URL을 입력하면 서버에서 Video ID를 파싱해 저장한다. 수강 페이지에서 IFrame API로 임베드 재생하고, 영상 종료 이벤트를 감지해 진도를 자동 완료 처리한다.

---

## 8. 주요 화면 구성

| 페이지 | 내용 |
|--------|------|
| 홈 | 강의 목록, 카테고리 탐색 |
| 강의 상세 | 커리큘럼, 수강 신청 버튼 |
| 강의 시청 | YouTube 플레이어 + 커리큘럼 사이드바 |
| 마이페이지 | 수강 내역 및 진도율 |
| 관리자 페이지 | 강의 / 카테고리 / 회원 관리 |
