# 개발계획서

## 1. 기술 스택

### Frontend

| 기술 | 용도 |
|------|------|
| React 18 + TypeScript 5 | 프레임워크 |
| React Router v6 | 라우팅 |
| TanStack Query v5 | 서버 상태 관리 및 API 캐싱 |
| Zustand | 전역 상태 (로그인 유저 정보) |
| Tailwind CSS | 스타일 |
| React Hook Form + Zod | 폼 유효성 검사 |
| Axios | HTTP 클라이언트 |
| YouTube IFrame API | 영상 재생 및 완료 이벤트 감지 |

### Backend

| 기술 | 용도 |
|------|------|
| NestJS 10 + TypeScript 5 | 프레임워크 |
| Prisma 5 | ORM |
| PostgreSQL 16 | 데이터베이스 |
| Passport.js + JWT | 인증 |
| class-validator | DTO 유효성 검사 |
| Swagger | API 문서화 |

## 3. 인증 설계

| 토큰 | 유효기간 | 저장 위치 |
|------|----------|-----------|
| Access Token | 1시간 | 메모리 (Zustand) |
| Refresh Token | 7일 | httpOnly Cookie |

Access Token 만료 시 Refresh Token으로 자동 재발급하고, Refresh Token도 만료되면 재로그인을 요구한다.

### 역할별 Guard

```
STUDENT → JwtAuthGuard
ADMIN   → JwtAuthGuard + RolesGuard(ADMIN)
```

## 4. YouTube 영상 연동 흐름

1. 관리자가 강의 단위 등록 시 YouTube URL 입력
2. 서버에서 Video ID 파싱 후 `youtube_video_id` 컬럼에 저장
3. 프론트에서 IFrame API로 임베드 재생
4. `onStateChange === YT.PlayerState.ENDED` 감지
5. `POST /progress/complete` 호출 → 진도율 업데이트

## 6. 개발 규칙

- **포맷터**: Prettier / **린터**: ESLint
- **브랜치**: `main` / `develop` / `feature/*`
- **커밋**: Conventional Commits (`feat:`, `fix:`, `docs:`)
- **Backend**: 비즈니스 로직은 Service에서만, DTO에 class-validator 필수
- **Frontend**: 서버 데이터는 TanStack Query, UI 상태는 Zustand
