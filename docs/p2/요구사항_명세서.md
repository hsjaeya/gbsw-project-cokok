## 2. 기능 요구사항

### FR-01 회원가입

- 이메일, 비밀번호, 닉네임으로 가입할 수 있어야 한다.
- 이메일 중복 여부를 검사해야 한다.
- 비밀번호는 8자 이상, 영문 + 숫자 + 특수문자 조합이어야 한다.

### FR-02 로그인 / 로그아웃

- 이메일과 비밀번호로 로그인할 수 있어야 한다.
- 로그인 성공 시 Access Token(1h)과 Refresh Token(7d)을 발급해야 한다.
- Refresh Token은 httpOnly 쿠키로 저장해야 한다.
- 로그아웃 시 Refresh Token을 무효화해야 한다.

### FR-03 강의 목록 조회

- 승인된(APPROVED) 강의를 페이지네이션(12개/페이지)으로 조회할 수 있어야 한다.
- 카테고리, 난이도로 필터링할 수 있어야 한다.
- 강의 제목으로 키워드 검색이 가능해야 한다.

### FR-04 강의 상세 조회

- 강의 제목, 설명, 섹션/강의 단위 목록을 확인할 수 있어야 한다.
- 미리보기로 설정된 강의 단위는 비수강생도 시청할 수 있어야 한다.
- 평균 평점과 리뷰 목록을 확인할 수 있어야 한다.

### FR-05 강의 시청

- 로그인한 사용자는 강의 시청 페이지에 접근할 수 있어야 한다.
- 시청 페이지 첫 진입 시 서버에서 자동으로 수강 이력(enrollment)을 생성해야 한다.
- 시청 페이지는 YouTube 임베드 플레이어와 커리큘럼 사이드바로 구성되어야 한다.

### FR-06 수강 진도 관리

- 영상이 종료되면 해당 강의 단위를 자동으로 완료 처리해야 한다.
- 전체 강의 단위 수 대비 완료 수로 진도율(%)을 계산해 표시해야 한다.
- 마이페이지에서 수강 중인 강의와 진도율을 확인할 수 있어야 한다.

### FR-07 프로필 관리

- 닉네임, 이메일, 비밀번호를 수정할 수 있어야 한다.
- 프로필 이미지를 업로드하고 변경할 수 있어야 한다.

### FR-08 리뷰

- 수강 이력이 있는 사용자만 리뷰를 작성할 수 있어야 한다.
- 강의당 1인 1리뷰로 제한해야 한다.
- 별점(1~5)과 텍스트 내용으로 구성되어야 한다.
- 본인이 작성한 리뷰는 수정 및 삭제할 수 있어야 한다.
- 리뷰 목록은 페이지네이션으로 조회되어야 하며, 전체 평균 평점을 함께 반환해야 한다.

### FR-09 강사 - 강의 관리

- INSTRUCTOR 역할의 사용자는 강의 초안을 생성할 수 있어야 한다.
- 강의는 섹션 단위로 구성할 수 있어야 한다.
- 각 섹션에 YouTube URL과 제목으로 구성된 강의 단위를 등록할 수 있어야 한다.
- DRAFT 또는 REJECTED 상태의 강의만 수정/삭제할 수 있어야 한다.
- 심의 신청(submit)을 통해 강의를 PENDING 상태로 전환할 수 있어야 한다.

### FR-10 관리자 - 강의 심의

- PENDING 상태의 강의를 목록으로 조회할 수 있어야 한다.
- 강의를 승인(APPROVED) 또는 반려(REJECTED) 처리할 수 있어야 한다.
- 반려 시 반려 사유를 함께 저장해야 한다.

### FR-11 관리자 - 카테고리 관리

- 카테고리를 추가, 수정, 삭제할 수 있어야 한다.

### FR-12 관리자 - 회원 조회

- 전체 회원 목록을 페이지네이션으로 조회할 수 있어야 한다.

### FR-13 관리자 - 리뷰 관리

- 전체 리뷰 목록을 조회하고 삭제할 수 있어야 한다.

## 3. 비기능 요구사항

| ID | 구분 | 요구사항 |
|----|------|----------|
| NFR-01 | 성능 | 강의 목록 API 응답 시간 500ms 이하 |
| NFR-02 | 보안 | 비밀번호는 bcrypt로 해시 저장 |
| NFR-03 | 보안 | Refresh Token은 httpOnly, Secure, SameSite=Strict 쿠키로 저장 |
| NFR-04 | 보안 | CORS 설정으로 허용된 도메인만 API 접근 허용 |
| NFR-05 | 보안 | Helmet 미들웨어로 HTTP 보안 헤더 적용 |
| NFR-06 | 보안 | Rate Limiting — 로그인 10회/분, 회원가입 5회/시간, 전역 60회/분 |
| NFR-07 | 유지보수 | 모든 API는 Swagger로 문서화 |
| NFR-08 | UX | 로딩 및 에러 상태에 대한 UI 피드백 제공 |

## 4. 제약 사항

| 항목 | 내용 |
|------|------|
| 영상 호스팅 | 자체 업로드 미지원, YouTube URL만 허용 |
| YouTube URL | 유효하지 않은 URL은 서버에서 즉시 거부 |
| 강의 공개 | 관리자 승인(APPROVED) 상태만 수강생에게 노출 |
| 강의 수정 | DRAFT, REJECTED 상태만 수정 가능. PENDING, APPROVED는 불가 |
| 리뷰 작성 | 수강 이력 보유자만 가능, 강의당 1인 1회 |

## 5. 주요 유스케이스

### UC-01: 수강생이 강의를 수강하는 흐름

1. 강의 목록에서 탐색 (카테고리 필터 / 검색)
2. 강의 상세 페이지에서 커리큘럼 및 리뷰 확인
3. [강의 시작] 클릭 → 로그인 확인
4. 시청 페이지 첫 진입 시 자동으로 수강 이력 생성
5. 강의 단위 선택 → 영상 시청
6. 영상 종료 → 진도 자동 업데이트
7. 수강 완료 후 리뷰 작성

### UC-02: 강사가 강의를 등록하는 흐름

1. 강사 페이지 → [강의 생성]
2. 제목, 설명, 카테고리, 난이도 입력 (DRAFT 상태로 저장)
3. 섹션 추가 → 강의 단위에 YouTube URL 등록
4. [심의 신청] 클릭 → PENDING 상태로 전환
5. 관리자 검토 → 승인 시 수강생에게 공개

### UC-03: 관리자가 강의를 심의하는 흐름

1. 관리자 페이지 → 강의 목록 (PENDING 필터)
2. 강의 내용 검토
3. [승인] 또는 [반려 + 사유 입력] 처리
4. 강사는 반려 사유 확인 후 강의 수정 및 재신청 가능
