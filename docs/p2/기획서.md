## 1. 프로젝트 개요

| 항목 | 내용 |
|------|------|
| 프로젝트명 | COKOK (cook of king of king) |
| 버전 | v2.0 |

| 목표 | 강사 심의 시스템과 리뷰 기능을 갖춘 3-역할 강의 플랫폼 구축 |

---

## 2. 서비스 배경 및 목적

p1에서 구축한 기본 강의 플랫폼(수강/진도/관리자 강의 직접 등록)에서 한 단계 발전하여, 누구나 강사로 등록하고 강의를 제출할 수 있는 구조로 확장한다. 제출된 강의는 관리자가 심의(승인/반려)하는 과정을 거쳐 공개된다. 수강생은 수강 후 리뷰를 남길 수 있으며, 리뷰 평점이 강의 상세 페이지에 표시된다.

---

## 3. 사용자 역할

| 역할 | 설명 |
|------|------|
| STUDENT | 강의 탐색, 수강, 영상 시청, 진도 확인, 리뷰 작성 |
| INSTRUCTOR | 강의 초안 작성, 섹션/강의 단위 구성, 심의 신청 |
| ADMIN | 강의 심의(승인/반려), 카테고리 관리, 전체 회원 조회, 리뷰 관리 |

---

## 4. 핵심 기능

### 4.1 회원 (STUDENT)

| 기능 | 설명 |
|------|------|
| 회원가입 | 이메일 + 비밀번호 + 닉네임 |
| 로그인 / 로그아웃 | JWT Access Token + Refresh Token |
| 프로필 관리 | 닉네임, 이메일, 비밀번호 수정, 프로필 이미지 업로드 |
| 강의 탐색 | 카테고리 필터, 키워드 검색, 난이도 필터 |
| 강의 상세 조회 | 커리큘럼(섹션/강의 단위), 평균 평점, 리뷰 목록 확인 |
| 강의 시청 | YouTube IFrame 플레이어 + 커리큘럼 사이드바, 첫 진입 시 자동 수강 이력 생성 |
| 수강 진도 | 영상 완료 시 자동 완료 처리 및 진도율 표시 |
| 마이페이지 | 수강 중인 강의 목록 및 진도율 확인 |
| 리뷰 | 수강 강의에 별점 + 텍스트 리뷰 작성, 수정, 삭제 |

### 4.2 강사 (INSTRUCTOR)

| 기능 | 설명 |
|------|------|
| 강의 초안 생성 | 제목, 설명, 카테고리, 난이도, 썸네일 설정 |
| 커리큘럼 구성 | 섹션 추가 → 강의 단위(YouTube URL) 등록 |
| 강의 수정 | DRAFT 또는 REJECTED 상태 강의만 수정 가능 |
| 심의 신청 | DRAFT/REJECTED → PENDING으로 상태 변경 후 관리자 검토 요청 |
| 강의 삭제 | DRAFT/REJECTED 상태 강의만 삭제 가능 |

### 4.3 관리자 (ADMIN)

| 기능 | 설명 |
|------|------|
| 강의 심의 | PENDING 강의를 승인(APPROVED) 또는 반려(REJECTED + 사유) 처리 |
| 카테고리 관리 | 카테고리 추가, 수정, 삭제 |
| 회원 목록 조회 | 전체 회원 목록 페이지네이션 조회 |

---

## 5. 강의 상태 흐름

```
DRAFT ──→ PENDING ──→ APPROVED
  ↑              └──→ REJECTED
  └─────────────────────┘
```

| 상태 | 설명 |
|------|------|
| DRAFT | 강사가 작성 중인 초안. 공개되지 않음 |
| PENDING | 심의 신청 완료. 관리자 검토 대기 중 |
| APPROVED | 관리자 승인 완료. 수강생에게 공개 |
| REJECTED | 관리자 반려. 강사가 수정 후 재신청 가능 |

## 8. YouTube 영상 연동 방식

강사가 강의 단위에 YouTube URL을 입력하면 서버에서 Video ID를 파싱해 저장한다. 유효하지 않은 URL은 `400 Bad Request`로 즉시 거부한다. 수강 페이지에서 IFrame API로 임베드 재생하고, 영상 종료 이벤트를 감지해 진도를 자동 완료 처리한다.
