## 2. 기능 요구사항

### FR-01 이메일 구독

- 사용자는 이메일로 신규 강의 알림을 구독할 수 있어야 한다.
- 구독 시 이메일 중복 구독을 방지해야 한다.
- 구독 해지 기능이 있어야 한다.

### FR-02 디스코드 구독

- 사용자는 디스코드 Webhook URL을 등록하여 알림을 받을 수 있어야 한다.
- 등록된 Webhook URL로 이벤트 발생 시 메시지를 발송해야 한다.

### FR-03 스케쥴러 - 주간 강의 요약

- 매주 월요일 오전 9시에 인기 강의 Top 5를 이메일 구독자에게 자동 발송해야 한다.
- 인기 강의는 수강생 수 기준으로 정렬한다.

### FR-04 스케쥴러 - 수강 독려 알림

- 7일 이상 진도 업데이트가 없는 수강생에게 독려 이메일을 자동 발송해야 한다.
- 이미 완료된 강의는 대상에서 제외해야 한다.

### FR-05 스케쥴러 - 오래된 로그 정리

- 30일 이상 된 시스템 로그를 자동 삭제해야 한다.

### FR-06 Webhook - 심의 결과 알림

- 강의 승인 또는 반려 시 강사의 등록 Webhook URL로 결과를 POST 요청해야 한다.
- Webhook 발송 이력(URL, 상태코드, 응답시간, 성공여부)을 저장해야 한다.
- 발송 실패 시 최대 3회 재시도해야 한다.

### FR-07 결제 - 강의 구매

- 사용자는 유료 강의를 토스페이먼츠로 결제할 수 있어야 한다.
- 결제 완료 후 서버에서 토스페이먼츠 API로 결제를 검증해야 한다.
- 검증 성공 시 결제 내역을 저장하고 수강 이력을 생성해야 한다.

### FR-08 결제 - 내역 조회

- 사용자는 마이페이지에서 결제 내역을 조회할 수 있어야 한다.
- 결제 상태(PENDING, PAID, FAILED, REFUNDED)를 확인할 수 있어야 한다.

### FR-09 결제 - 환불

- 관리자는 결제 건에 대해 환불 처리를 할 수 있어야 한다.
- 환불 시 수강 이력을 삭제해야 한다.

### FR-10 보안 - XSS 방어

- 사용자 입력값(강의 제목, 설명, 리뷰 내용 등)에 XSS 공격 방어 처리를 해야 한다.
- CSP(Content Security Policy) 헤더를 설정해야 한다.

### FR-11 보안 - SQL 인젝션 방어

- 모든 DB 쿼리는 Prisma ORM 파라미터 바인딩을 사용해야 한다.
- raw query 사용을 금지하고, 불가피한 경우 파라미터 바인딩을 강제해야 한다.

### FR-12 보안 - 감사 로그

- 관리자의 주요 작업(강의 승인/반려, 회원 역할 변경, 카테고리 삭제)은 감사 로그로 기록해야 한다.
- 감사 로그는 관리자 페이지에서 조회할 수 있어야 한다.

### FR-13 모니터링 - 헬스체크

- `/health` 엔드포인트에서 서버 및 DB 연결 상태를 반환해야 한다.

### FR-14 모니터링 - 구조화된 로그

- 모든 API 요청과 응답을 JSON 형식으로 로깅해야 한다.
- 요청별 처리 시간을 로그에 포함해야 한다.

### FR-15 성능 - DB 최적화

- 강의 목록 조회 쿼리에 인덱스를 적용해야 한다.
- N+1 쿼리 문제를 제거해야 한다.

### FR-16 성능 - 프론트 최적화

- React.memo, useMemo, useCallback으로 불필요한 리렌더링을 방지해야 한다.
- 라우트 기반 코드 스플리팅을 적용해야 한다.
- 강의 썸네일에 lazy loading을 적용해야 한다.

## 5. 주요 유스케이스

### UC-01: 사용자가 유료 강의를 결제하는 흐름

1. 강의 상세 페이지에서 [결제하기] 클릭
2. 토스페이먼츠 결제창 호출
3. 결제 완료 후 서버로 paymentKey, orderId, amount 전달
4. 서버에서 토스페이먼츠 API로 결제 검증
5. 검증 성공 → 수강 이력 생성 → 강의 시청 시작

### UC-02: 강의 승인 시 알림 발송 흐름

1. 관리자가 강의 승인(APPROVE) 처리
2. 이메일 구독자 전체에게 신규 강의 알림 이메일 발송
3. 강사의 등록 Webhook URL로 승인 결과 POST
4. 발송 결과 로그 저장

### UC-03: 스케쥴러 - 주간 강의 요약 발송 흐름

1. 매주 월요일 오전 9시 스케쥴러 트리거
2. 수강생 수 기준 인기 강의 Top 5 조회
3. 이메일 구독자 목록 조회
4. 각 구독자에게 요약 메일 발송
